    Install Campus Planner

    Install options depend on your browser and device.

    • Chrome or Edge desktop: use the Install icon in the address bar or the browser menu.
    • Android: open your browser menu and choose Install app or Add to Home screen, when offered.
    • iPhone / iPad: open the site in Safari, tap Share, then Add to Home Screen.

    For reliable testing, use HTTPS or localhost. If already installed, your browser may not offer the option again.
    ✦

    How offline mode works

    Campus Planner combines three separate pieces:

    • Manifest: tells supporting browsers how the app can be installed and displayed.
    • Service Worker + Cache API: save the app shell and serve it when network access is unavailable.
    • Local Storage: saves your tasks in this browser, including tasks added offline.

    There is no backend or cross-device sync. The first online visit is needed to prepare the offline app shell.
